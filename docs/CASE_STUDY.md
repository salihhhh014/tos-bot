# ToS Bot — кейс проекта

## Задача

Люди подписывают оферты, пользовательские соглашения и политики конфиденциальности,
не читая мелкий шрифт. Юрист для каждого документа — дорого и долго, а «прочитать глазами»
не хватает времени и внимания.

Нужен инструмент, который за минуту отвечает:

- о чём документ;
- какие в нём риски и невыгодные условия;
- насколько он опасен;
- где именно в тексте написано то, о чём говорит бот.

## Решение

Telegram-бот на Python:

- принимает PDF, DOCX, TXT, фото скана, ссылку или текст;
- распознаёт сканы через Mistral OCR;
- режет длинные документы на части и собирает единый отчёт (map-reduce);
- кэширует повторные разборы по sha256;
- ограничивает дневное потребление на пользователя;
- даёт кнопку дословной цитаты, чтобы проверить любой тезис;
- поддерживает fallback-провайдера при 429/сбоях.

## Стек

Python 3.12, aiogram 3, OpenAI-совместимый API (Groq + Qwen), Mistral OCR,
SQLite, httpx, trafilatura, pypdf, python-docx, pytest, ruff, GitHub Actions, Docker.

## Что технически интересно

- **Map-reduce пайплайн** для документов длиннее контекста модели.
- **Кэш и квоты** как защита от расходов на API.
- **Fallback между провайдерами** без усложнения UX.
- **SSRF-защита**: проверка DNS, портов, схемы и каждого редиректа.
- **Redaction логов** и отказ от хранения файлов.
- **Graceful shutdown** и корректное закрытие сессии Telegram.
- **59 тестов** на пайплайн, квоты, OCR, SSRF, кэш и утилиты.

## Безопасность и ограничения

- Бот не является юридической консультацией.
- Текст уходит внешним провайдерам (Groq, Mistral OCR).
- Сканы могут ошибаться в цифрах и суммах — их нужно сверять с оригиналом.
- Квота и настройки на free-плане Render обнуляются после рестарта.
- Кнопка цитат хранит последние 3 документа только в памяти процесса.

## Результат

- Рабочий Telegram-бот с понятным сценарием.
- CI: линтер + тесты на каждый push.
- Docker и Render-конфиг.
- Честно описанные ограничения и модель угроз.

## Для заказчика

Проект легко адаптируется под:

- юридические и compliance-команды;
- SaaS с пользовательскими соглашениями;
- агентства, которые проверяют документы клиентов;
- внутренние боты для анализа договоров.

Что меняется под заказ: промпт, язык, источники документов, формат отчёта,
интеграция с CRM/Google Docs/PDF-экспортом, тарифы и оплата.
